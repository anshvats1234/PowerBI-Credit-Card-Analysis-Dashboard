**Credit Card Analysis Dashboard**

**Project Overview**
Developed an interactive Power BI dashboard to analyze credit card customer behavior and transaction performance. The dashboard provides insights into revenue trends, customer demographics, expenditure patterns, and card category performance.

**Dashboard Pages**

- Credit Card Transaction Report
- Credit Card Customer Report

**Tools Used**

- Power BI
- Excel
- DAX
- Power Query

**Key Metrics**

- Revenue Analysis
- Transaction Count
- Interest Earned
- Customer Demographics
- Income Group Analysis
- Card Category Analysis

**Dashboard Features**

- Revenue by Card Category
- Customer Segmentation
- Transaction Trends
- Education Analysis
- Income Group Analysis
- Expenditure Category Analysis
- Interactive Filters and Slicers

**Skills Demonstrated**

- Data Cleaning
- Data Modeling
- DAX Calculations
- Data Visualization
- Business Analysis
- Dashboard Design
